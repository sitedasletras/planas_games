# PLANAS FORMULA RACING MANAGER — Roteiro de Design

> Documento de referência fornecido pelo dono do projeto em 12/08/2026.
> Serve como roteiro-base para os futuros jogos de Fórmula 1, Fórmula 2,
> Fórmula Indy e Fórmula E dentro da plataforma World Special Player (WSP).
> Ainda não iniciado — guardado aqui para consulta quando entrarmos nessa fase.

## CONCEITO GERAL

Crie um jogo de gerenciamento e simulação de Fórmula 1 chamado provisoriamente PLANAS FORMULA RACING MANAGER.

O jogador não controla diretamente o carro durante a corrida. Ele assume o papel de proprietário, presidente e chefe de uma equipe de Fórmula 1, sendo responsável por construir a equipe desde sua criação, administrar cada temporada, desenvolver o carro, contratar pilotos e funcionários, negociar patrocinadores, controlar o orçamento, escolher motores e pneus, definir estratégias e tomar decisões durante os fins de semana de corrida.

O objetivo é criar uma experiência profunda, realista, estratégica e viciante, na qual cada decisão tenha consequências.

O jogo deve permitir campanhas de curto, médio e longo prazo, com temporadas completas, evolução tecnológica, mudanças de regulamento, desenvolvimento de pilotos, crescimento financeiro, rivalidades e possibilidade de criar uma equipe que se torne uma potência mundial.

## 40. MODOS DE JOGO

- **Carreira** — uma equipe por várias temporadas.
- **Temporada** — escolher uma temporada e jogar apenas aquele campeonato.
- **Equipe Personalizada** — criar uma equipe do zero.
- **Construtor de Circuitos** — criar pistas.
- **Campeonato Personalizado** — criar regras e calendário.
- **Desafios** — situações especiais (ex: "assuma uma equipe em último lugar faltando cinco corridas").
- **Modo Dinastia** — jogar por décadas e construir um império esportivo.

---

## 41. PRINCÍPIO FUNDAMENTAL DO JOGO

O jogo não deve ser simplesmente uma sequência de menus. Cada decisão deverá possuir consequência.

Exemplos:

- Economizar demais → carro menos competitivo.
- Gastar demais → problemas financeiros.
- Contratar piloto jovem → menor experiência, mas grande potencial.
- Contratar veterano → maior experiência, mas menor evolução.
- Investir em aerodinâmica → carro mais rápido, porém mais caro.
- Investir em confiabilidade → menos abandonos, porém menor velocidade.
- Pneus agressivos → mais velocidade, maior desgaste.
- Estratégia conservadora → menor risco, porém menor possibilidade de vitória.

---

## 42. OBJETIVO FINAL

Criar um simulador de gestão de Fórmula 1 no qual o jogador sinta que está realmente comandando uma equipe durante uma temporada inteira.

A experiência deverá combinar: gestão esportiva + engenharia + estratégia + economia + desenvolvimento tecnológico + mercado de pilotos + patrocinadores + clima + corridas + construção de circuitos + evolução histórica.

O jogo deverá permitir que cada carreira produza uma história diferente. Uma equipe criada pelo jogador poderá começar pequena, sobreviver com orçamento limitado, construir sua própria fábrica, desenvolver um carro competitivo, contratar um jovem talento, conquistar seu primeiro pódio, vencer uma corrida, disputar o campeonato e eventualmente se tornar uma das maiores equipes da história do universo do jogo.

### Requisito técnico

Estruture o projeto de forma modular e escalável. Separar claramente: motor de simulação, banco de dados, sistema financeiro, sistema de pilotos, sistema de equipes, sistema de carros, sistema de pneus, sistema meteorológico, sistema de corridas, sistema de circuitos, editor de pistas, IA, sistema de temporadas, sistema de regulamentos, interface, salvamento, estatísticas.

Não criar uma demonstração superficial. Construir a arquitetura pensando em um jogo que possa receber novos circuitos, temporadas, pilotos, equipes, regulamentos, tecnologias e funcionalidades no futuro.

Priorizar inicialmente um MVP jogável, mas estruturar o código para permitir expansão progressiva sem precisar reconstruir o projeto inteiro.

O resultado final deverá transmitir a sensação de que o jogador não está apenas "jogando Fórmula 1", mas construindo e comandando uma organização de automobilismo ao longo de décadas.

Este documento é a visão completa/final para F1, F2, Indy e Fórmula E. É um
escopo de jogo AAA — não dá para construir tudo de uma vez. Quando chegar a
hora, o caminho será: extrair um MVP jogável (provavelmente: criar equipe →
um fim de semana de corrida simulado → resultado), validar que a simulação
básica funciona e diverte, e então ir camada por camada (patrocínios,
desenvolvimento de carro, mercado de pilotos, clima, editor de circuito
etc.) — o mesmo padrão que usamos no módulo de futebol.
